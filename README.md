# VIXフェーズはS&P500将来リターン分布を識別するか

### 〜重複リターン・自己相関・分散不均一性を考慮した統計的検証〜

## 概要

本プロジェクトでは、VIX（恐怖指数）の水準がS&P500の将来リターンに与える影響を、過去34年分のデータを用いて統計的に検証した。

単に「VIXが高いと将来リターンが高いか」を確認するだけでなく、ANOVA、Welch ANOVA、Kruskal-Wallis検定、Welch型ペアワイズ比較、重回帰分析、HAC（Newey-West）補正、さらにlog残差二乗モデルによる分散分析を行い、通常の検定で観測される有意性がどの程度頑健であるかを検証した。

本研究の中心的な結論は、VIXフェーズ間でS&P500の6ヶ月先リターン分布に差は観測される一方で、その有意性は重複リターンに起因する自己相関によって大きく増幅されている可能性が高い、という点である。HAC補正後の平均モデルおよびlog残差二乗モデルでは、VIX_Zは5%水準で将来リターンの平均・分散を有意に説明しなかった。

---

## 1. 背景と目的

投資経験上、VIXが急騰するパニック相場では、その後のS&P500リターンが高くなる局面があるように見える。しかし、この関係が統計的に再現性を持つものなのか、それとも重複リターンや自己相関によって見かけ上強く観測されているだけなのかは慎重に検証する必要がある。

本研究の目的は、VIX水準がS&P500の6ヶ月先リターンの平均・分布・分散をどの程度識別できるかを明らかにすることである。

---

## 1.1 検証仮説

本研究では以下の仮説を設定した。

### 仮説1：VIXフェーズ間の平均リターン差

- H0：VIXフェーズ間でS&P500の6ヶ月先リターンの平均に差はない。
- H1：少なくとも1つのVIXフェーズにおいて、6ヶ月先リターンの平均が異なる。

### 仮説2：VIXフェーズ間の分散差

- H0：VIXフェーズ間でS&P500の6ヶ月先リターンの分散は等しい。
- H1：VIXフェーズ間でS&P500の6ヶ月先リターンの分散は異なる。

### 仮説3：各VIXフェーズ間のペアワイズな差

- H0：各VIXフェーズのペア間で6ヶ月先リターンの平均に差はない。
- H1：各VIXフェーズのペア間で6ヶ月先リターンの平均に差がある。

### 仮説4：重複リターン補正後の頑健性

- H0：自己相関の影響を緩和した場合、VIXフェーズ間で6ヶ月先リターンに差はない。
- H1：自己相関の影響を緩和しても、VIXフェーズ間で6ヶ月先リターンに差がある。

### 仮説5：HAC補正後のVIX予測力

- H0：自己相関および不均一分散を補正した場合、VIX_Zの回帰係数は0である。
- H1：自己相関および不均一分散を補正しても、VIX_Zの回帰係数は0ではない。

### 仮説6：VIX・金利による将来リターン分散の説明

- H0：VIX_Zおよび米国10年国債利回りは、S&P500の6ヶ月先リターンの条件付き分散を説明しない。
- H1：VIX_Zまたは米国10年国債利回りは、S&P500の6ヶ月先リターンの条件付き分散を説明する。

---

## 2. 使用データと手法

- データソース：Yahoo Finance API（yfinance）
- 取得期間：1990年1月1日〜2024年1月1日
- 対象指標：
  - S&P500（^GSPC）
  - VIX（^VIX）
  - 米国10年国債利回り（^TNX）
- 目的変数：
  - S&P500の6ヶ月先リターン
- 主な分析手法：
  - ANOVA
  - Welch ANOVA
  - Kruskal-Wallis検定
  - Tukey HSD
  - Welch型ペアワイズ比較 + Holm補正
  - 間引きANOVA
  - OLS回帰
  - HAC（Newey-West）補正
  - log残差二乗モデル

---

## 3. 統計的前提の検証

### 3.1 ANOVA・代替検定

VIXフェーズ間でS&P500の6ヶ月先リターンに差があるかを検証した。

| Test | Statistic | p-value |
|---|---:|---:|
| Standard one-way ANOVA | 178.7302 | 2.5734e-112 |
| Welch ANOVA | 94.3433 | 1.9428e-51 |
| Kruskal-Wallis | 354.9408 | 1.2700e-76 |

通常ANOVAだけでなく、等分散性を仮定しないWelch ANOVA、非正規性に比較的頑健なKruskal-Wallis検定でも有意差が確認された。したがって、日次データ上ではVIXフェーズ間で将来リターン分布が同一であるという帰無仮説は棄却される。

---

### 3.2 等分散性の検証

| Test | Statistic | p-value |
|---|---:|---:|
| Levene center=mean | 362.3223 | 3.3268e-221 |
| Levene center=median / Brown-Forsythe | 315.8262 | 3.1148e-194 |
| Bartlett | 931.3339 | 1.4137e-201 |

いずれの検定でもp値は極めて小さく、VIXフェーズ間で等分散性の仮定は明確に棄却された。これは、高VIX局面では平均リターンだけでなく、リターン分布のばらつきも変化していることを示唆する。

---

### 3.3 Welch型ペアワイズ比較

等分散性が棄却されたため、Tukey HSDに加えて、等分散性を仮定しないWelch型ペアワイズ比較を実施し、Holm法により多重比較補正を行った。

| Comparison | Mean Diff | Holm adjusted p-value | Reject at 5% |
|---|---:|---:|---:|
| Normal vs Alert | -0.0074 | 8.4032e-03 | True |
| Normal vs Fear | 0.0698 | 4.3134e-30 | True |
| Normal vs Panic | 0.1293 | 4.8137e-22 | True |
| Alert vs Fear | 0.0772 | 2.7588e-32 | True |
| Alert vs Panic | 0.1368 | 1.5587e-23 | True |
| Fear vs Panic | 0.0596 | 1.2125e-05 | True |

すべてのペアでHolm補正後も5%水準の有意差が確認された。特に、Alert局面ではNormal局面より平均リターンが低下する一方、FearおよびPanic局面では平均リターンが大きく上昇している。

---

## 4. 独立性違反と重複リターン問題

6ヶ月先リターンを日次データから作成しているため、隣接する観測値同士で将来リターンの計算期間が大きく重複する。

実際、ANOVA残差のDurbin-Watson統計量は0.0321、回帰残差のDurbin-Watson統計量は0.0202であり、強い正の自己相関が確認された。

### 4.1 間引きANOVA

重複リターンの影響を確認するため、21営業日、63営業日、126営業日ごとにサンプルを間引いた。

| Sampling | N | ANOVA p-value | Welch p-value | Kruskal p-value |
|---|---:|---:|---:|---:|
| Daily | 8346 | 2.5734e-112 | 1.9428e-51 | 1.2700e-76 |
| Monthly_21d | 398 | 2.9868e-05 | 1.6026e-03 | 3.5405e-04 |
| Quarterly_63d | 133 | 2.1711e-01 | 3.6381e-01 | 3.1136e-01 |
| Semiannual_126d | 67 | 2.3580e-01 | 4.0247e-01 | 4.9688e-01 |

日次データおよび21営業日間引きでは有意差が残った一方、63営業日および126営業日まで間引くと有意差は確認されなかった。

この結果は、VIXフェーズ間の差が完全な偶然ではない一方で、通常ANOVAにおける極端な有意性は、重複リターンに起因する自己相関によって増幅されている可能性を示している。

---

## 5. HAC補正による平均モデルの再評価

VIX_Zと米国10年国債利回りを説明変数とする多変量回帰モデルを推定し、Newey-West型HAC推定量により自己相関および不均一分散に頑健な標準誤差を用いて有意性を再評価した。

| Variable | OLS p-value | HAC p-value |
|---|---:|---:|
| const | 1.0984e-80 | 2.1528e-02 |
| VIX_Z | 5.3810e-13 | 9.5462e-02 |
| Treasury_10Y | 5.3251e-03 | 7.3259e-01 |

OLSではVIX_ZおよびTreasury_10Yはいずれも有意であった。しかし、HAC補正後にはVIX_Zのp値は0.095となり、5%水準では有意ではなくなった。また、Treasury_10Yの有意性は完全に消失した。

したがって、通常OLSで観測された強い有意性の多くは、重複リターンに起因する自己相関によって過大評価されていた可能性が高い。

---

## 6. log残差二乗モデルによる分散の検証

VIXは本来、市場の期待変動率を反映する指標であるため、平均リターンよりも将来リターンの分散を説明する可能性がある。そこで、平均モデルの残差を用いて、以下の補助回帰を行った。

```text
log(ε² + c) = γ0 + γ1 VIX_Z + γ2 Treasury_10Y + u
```

| Variable | Log Coef | Log p-value |
|---|---:|---:|
| const | -6.0392 | 2.9691e-43 |
| VIX_Z | 0.0810 | 2.5805e-01 |
| Treasury_10Y | -0.0204 | 8.3545e-01 |

log残差二乗モデルにおいて、VIX_Zの係数は正であったものの、p値は0.258であり統計的に有意ではなかった。また、Treasury_10Yも有意ではなかった。

したがって、本分析ではVIX_Zおよび金利が、平均モデルで説明しきれなかった将来リターンの分散を明確に説明するという証拠は得られなかった。

---

## 7. 結論

本研究では、VIXフェーズがS&P500の6ヶ月先リターン分布を識別するかを検証した。

通常のANOVAでは、VIXフェーズ間の平均リターンに極めて強い有意差が確認され、帰無仮説は棄却された。また、Welch ANOVA、Kruskal-Wallis検定、Welch型ペアワイズ比較においても、日次データ上ではVIXフェーズ間の差が確認された。

一方で、等分散性は明確に棄却され、ANOVA残差および回帰残差には強い自己相関が確認された。さらに、21営業日間引きでは有意差が残ったものの、63営業日および126営業日間引きでは有意差は確認されなかった。

また、HAC補正後の回帰分析では、VIX_Zは5%水準では有意ではなく、log残差二乗モデルでもVIX_Zおよび金利は将来リターン分散を有意に説明しなかった。

以上より、本研究は以下の3点を結論とする。

1. VIXフェーズ間でS&P500の6ヶ月先リターン分布が同一であるという帰無仮説は、日次および21営業日間引きサンプルでは棄却される。
2. しかし、その有意性は重複リターンに起因する自己相関によって大きく増幅されており、63営業日・126営業日間引きおよびHAC補正後には5%水準の強い予測力は確認されない。
3. VIX_Zおよび金利は、log残差二乗モデルにおいて将来リターン分散を有意に説明しなかった。

したがって、VIXはS&P500の将来リターンの平均または分散を単独で強く予測する指標とは言い切れない。ただし、VIXフェーズは日次データ上で将来リターン分布の違いを識別しており、市場ストレス状態を分類する補助的な指標としては一定の有用性を持つと考えられる。

本研究の主な意義は、VIXと将来リターンの関係を単に確認するだけでなく、通常の検定で観測される強い有意性が、重複リターンと自己相関によって過大評価されうることを示した点にある。
